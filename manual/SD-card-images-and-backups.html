SD card images and backups#

The sBitx is a computer as well as a transceiver: its Raspberry Pi runs Raspberry Pi OS from a microSD card. An image is a complete copy of such a card (the operating system, jeSDR and its set-up) in one file. Writing an image to a card is like reformatting a computer's disk and restoring it: everything on the card is replaced.

Use an image for a fresh start, a new or failed card, or to get back to a known-good system. To add jeSDR to a card that already runs Raspberry Pi OS, or to update it, you don't need an image: see Installing and updating.

Your radio'sWhat keeps it
settings, log, calibration, voice messagesMore → Backup → Download a backup (one small file)
everything on the carda whole-card copy (below)

The calibration (hw_settings.ini) belongs to your radio's own boards, so keep a backup of it whatever else you do.

Writing the jeSDR image#

You need a computer (Windows, macOS or Linux), a microSD card of 16 GB or more (32 GB gives room for recordings and other programs) and a card reader.

  1. Download the SD card image from the releases page.
  2. Install Raspberry Pi Imager or balenaEtcher. Both write the compressed file (.img.xz or .img.gz) directly; there is no need to unpack it first.
  3. Write it:
    • Raspberry Pi Imager: Choose OS → Use custom, pick the image; Choose storage, pick the card; Next. When it offers to customise the settings, choose No: the image is already set up.
    • balenaEtcher: Flash from file, Select target, Flash.
  4. Eject the card, put it in the radio and switch on.

The first start takes a little longer: the card is expanded to its full size, and the radio makes its own HTTPS certificate and SSH keys. Then restore your backup in More → Backup → Restore from a file…. The image is made on a Pi 4: on a Pi 5, run the one-line installer once after the first start.

If the card isn't recognised, try another reader or USB port, and make sure the card is big enough. A card that fails to write twice is probably worn out: SD cards do fail, especially cheap ones.

Without opening the case#

The Pi can start from a USB drive instead of its internal card. That lets you try an image without touching the card inside, or copy a new image onto the internal card from the radio itself.

Start the radio from a USB drive#

  1. Write the image to a USB drive of 16 GB or more, as above (choose the USB drive as the target).
  2. On the radio, open a terminal and run sudo raspi-config. Choose Advanced Options → Boot Order → USB Boot (NVMe/USB Boot on newer versions), then Finish.
    • If that gives an error, connect the radio to the internet, choose Update in raspi-config, then Advanced Options → Bootloader Version → Latest, reboot and try again.
  3. Shut down, plug in the USB drive and switch on. The first start from USB takes a few minutes.

To go back to the internal card, remove the USB drive and restart. With no USB drive the Pi looks for one for a few seconds, then starts from the card.

Copy the USB drive onto the internal card#

With the radio running from the USB drive:

  1. Back up anything you want from the internal card first (it is about to be replaced).
  2. Open the Raspberry Pi menu → Accessories → SD Card Copier.
  3. Copy From Device: the USB drive you started from (usually /dev/sda). Copy To Device: the internal card (/dev/mmcblk0).
  4. Tick New Partition UUIDs, check both choices again, and press Start. It asks before it overwrites the card.
  5. When it finishes, shut down, remove the USB drive and switch on: the radio starts from the freshly copied card.

Backing up the whole card#

A copy of the whole card brings back everything at once, including other programs and their settings.

On the radio, to a USB drive at least as big as the card (it erases the drive): Raspberry Pi menu → Accessories → SD Card Copier, Copy From the internal card (/dev/mmcblk0), Copy To the USB drive (usually /dev/sda), Start. To restore, start from that drive and copy it back (above), or swap the card.

On a computer, as an image file: take the card out of the radio and read it with Win32 Disk Imager (Read) on Windows, or dd on Linux or macOS:

sudo dd if=/dev/sdX of=radio-backup.img bs=4M status=progress

(/dev/sdX is the card reader; check it with lsblk first, because dd to the wrong device erases it.) The file is the card's full size; write it back with Raspberry Pi Imager or balenaEtcher like any other image.

A copy of your card contains your Wi-Fi passwords, the radio's own keys and certificate, and your log. Keep it for yourself; don't share it as an image for others.

Moving to a new card#

  1. More → Backup → Download a backup on the old card.
  2. Write the jeSDR image to the new card and start the radio with it.
  3. More → Backup → Restore from a file… with the backup.

Programs you added yourself (WSJT-X, fldigi, JS8Call…) are not in the backup: install them again, or use a whole-card copy instead. Their own logs are in your home folder: ~/.local/share/WSJT-X/, ~/.local/share/JS8Call/ and ~/.fldigi/.
