jeSDR 1.5.0

Console commands#

The console is for set-up, status and calibration. Open it with telnet <radio> 8081, or type into the terminal running jesdr in the foreground. Commands are not case-sensitive. Every setting can also be set by its console name (see All settings): <NAME> <value>, for example WPM 20; <NAME> "" empties a text setting; set lists them all.

status                  radio state, TX source, power/SWR, connected clients,
                        audio underrun counts, which I2C bus is in use
freq <hz>               tune
mode <USB|LSB|CW|CWR|AM|FM|DIGI|JS8|FT8|FT4|FT2|JTTY|RTTY|PSK|RADE>
bw <hz>   if <0-100>   audio <0-100>   drive <1-100>   mic <0-50>
agc <OFF|SLOW|MED|FAST>
tx | rx                 key / un-key with the local mic
tune on|off             carrier at the tune power for the tune time
twotone on|off          two-tone test, 700 + 1900 Hz USB at the Drive (dummy load)
mute on|off
rit on|off|clear|<hz>   receive incremental tuning
xit on|off|clear|<hz>   transmit incremental tuning (adds to split)
band [<80m..10m> [1-3]] band stacking registers (no arguments: list them)
maxvswr <1.0-10.0|0>    SWR protection threshold (0 disables: not recommended)
swrreset                clear an SWR trip
swrscan [points|stop]   SWR across the band the dial is on
ifauto learn            auto IF gain: learn the band noise now
smcal s9 | clear | <dB> S-meter on this band: calibrate to S9 / clear / set dB
txcal start [W] [bands] PA power calibration into a DUMMY LOAD
txcal stop|status
bridgecal <W>           while TUNE is keyed: match the power reading to a wattmeter (sets BRIDGE)
lpfsweep start [W] [A,B,C,D] sweep the output low-pass filters into a DUMMY LOAD
lpfsweep show [all] | stop | status  the stored result (all: every frequency)
diag pa|rx|bridge|audio|bias [...]  diagnostics (diag help; see Diagnostics)
diag freq [MHz] | freq apply  frequency calibration from WWV/WWVH (see PA power and calibration)
diag show <test> | stop | status
diag bias [adjust|manual] | bias done [base_mA now_mA]  PA bias adjustment
txplan                  the transmit band plan in use
cluster [status|hist|reconnect|send <text>|on|off]
cwtext <text> | cwstop  send text in CW / stop
zerobeat                CW/CWR: tune onto the signal the zero-beat indicator reads
vk play N [repeat] | vk rec N | vk listen N | vk stop | vk delete N
rec start|stop|toggle|list|delete <name>
ft8 <verb> ...          cq, hunt on|off, reply, tx, text, enable, halt, parity, txhz, dx, report, log, clear
jtty <verb> ...         send <text>, stop, txhz <hz>, clear
js8 [status]            the link to JS8Call (JS8 mode)
js8 <verb> ...          send <text>, speed slow|normal|fast|turbo, halt, launch, inbox, calls, raise, clear [band|msgs|calls|all]
headset                 the headset / USB sound card: what is chosen, and the devices, numbered
headset phones|mic <n|name|off>   choose the headphones or microphone (n from that list)
reporter [status]       FreeDV Reporter: the connection and how many stations
rtty <verb> ...         send <text>, stop, txhz <hz>, clear
psk <verb> ...          send <text>, stop, txhz <hz>, clear
cty <call>              country-file lookup
cty update|reload       download the newest country file / read the file again
gps setclock | gps grid set the clock / MYGRID from the GPS now
solar [refresh|on|off]  band conditions: SFI, A/K, MUF, HF day/night
clock [check|set|rtcwrite|rtcread|sync]  the Pi clock and RTC against network time
system poweroff|reboot  shut down or restart the Pi (un-keys and saves first)
system stop|relaunch    stop jeSDR (the Pi stays on) / restart jeSDR
set                     list every setting
save                    write the settings now
exit                    stop the daemon
help                    list the commands

The web UI cannot send internal commands or exit; it stops jeSDR only through More → Shut down.
